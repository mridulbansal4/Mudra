## 4. Team Size, Eligibility Rules & Geographic Restrictions

Verified from `Yx`, `Zx`, and `tS` in `https://reskilll.com/hack/nexconn/assets/Rules-DQNF0983.js` and `index-DSX23m3q.js`:

1. **Team Size**: **1 to 4 members per team** (`Solo participants are eligible and compete as a team of 1`).
2. **Team Governance**:
   - One member creates the team (becoming the **Team Leader**) and shares a team invite code (`Team code` in `Admin-_pGkMjvW.js`) with up to 3 teammates.
   - **Only the Team Leader** can select/change the team's competition track and submit or update the project (`Submit-R3OJNUmD.js`).
3. **Geographic Eligibility (`tS = ["CN"]`)**:
   - Open to developers **worldwide**, with one hard country exclusion in code (`tS = ["CN"]`): **residents of Mainland China are excluded** (because RongCloud operates a separate domestic Chinese business and Nexconn is strictly its international Singapore-based entity `RCLOUD GLOBAL PTE. LTD.`).
4. **Prior Work & Pre-Existing Code (`builtBefore`)**:
   - Permitted if and only if declared honestly (`builtBefore: "yes"`) with a 10–2,000 character explanation (`builtBeforeDetails`) of what existed before October 23, 2026 versus what was built during the hackathon.

## 6. Submission Deliverables & Technical Verification Gates

Verified from `Submit-R3OJNUmD.js` (`https://reskilll.com/hack/nexconn/assets/Submit-R3OJNUmD.js`):

1. **Project Title (`title`)**: 5–200 characters.
2. **Project Summary (`summary`)**: 10–2,000 characters.
3. **Nexconn Packages Used (`packages`)**: Must select at least **`chat-sdk` (Chat SDK)** and/or **`chat-ui` (Chat UI)**. **`call-sdk` (Call SDK)** is optional and explicitly blocked from standalone submission (`!packages.includes("chat-sdk") && !packages.includes("chat-ui")` throws a validation error).
4. **Nexconn App Key (`appKey`)**: Regex `/^[A-Za-z0-9_-]{8,64}$/`. Mandatory telemetry key used by Nexconn judges to verify real API calls, message volume, and active users on `https://console.nexconn.ai`.
5. **SDK Feature Integration Description (`sdkFeatures`)**: 30–2,000 characters detailing which Nexconn Chat SDK / Chat UI features were used and where they operate in the app.
6. **Live App / Download Link (`appUrl`)**: Working `http(s)://` link to deployed web app, Android APK, iOS TestFlight, or store listing.
7. **Public GitHub Repository (`repoUrl`)**: Valid `https://github.com/{owner}/{repo}` URL. The submission form calls `https://api.github.com/repos/{owner}/{repo}` in real time to verify the repo exists and is public.
8. **Demo Video (`demoVideoUrl`)**: Hosted on **YouTube**, **Loom**, **Google Drive**, or **Vimeo**.
9. **Project Write-up PDF (`writeupUrl`)**: PDF document up to **25 MB** uploaded to `https://allbackend.reskilll.com/upload/document`. Must include the team's **Nexconn App Key** inside the PDF text.
10. **Traction Proof (`tractionUrl`, `activeUsers` - Optional Bonus)**: URL to traction proof plus integer count (`1–9` digits) of active users acquired during the hackathon.
11. **Prior Work Disclosure (`builtBefore`, `builtBeforeDetails`)**: Explicit `"no"` or `"yes"` (with 10–2,000 char disclosure if `"yes"`).

## 8. Allowed / Required Tech Stack & Sponsor Tools

- **Mandatory Sponsor Core**:
  - **Nexconn Chat SDK (`IMLib`)** - Web (`@rongcloud/imlib-next`), Android (`cn.rongcloud.sdk:im_lib`), iOS (`RongCloudIM/IMLibCore`), Flutter (`rongcloud_im_wrapper_plugin`), React Native (`@rongcloud/react-native-imlib`), or Unity (`RongCloud IM Unity`).
  - **OR Nexconn Chat UI (`UIKit`)** - Android (`cn.rongcloud.sdk:im_kit`), iOS (`RongCloudIM/IMKit`), or Web UIKit components.
- **Optional High-Leverage Sponsor Extensions**:
  - **Nexconn Call SDK (`CallLib` / `CallKit`)** - Web (`@rongcloud/engine`, `@rongcloud/calllib-v3`), Android, iOS, Flutter, React Native.
  - **Nexconn Server SDKs & Webhooks** - Node.js, Go, Java, Python, PHP, .NET (`POST /user/getToken.json`, message routing webhooks, pre-send moderation webhooks, online status webhooks).
  - **Nexconn AI Developer Tooling** - `nexconn-skills` (`https://github.com/NexconnAI-Dev/nexconn-skills`) and `@nexconn/console-mcp` (`npx -y @nexconn/console-mcp`).
- **Application Frameworks, Cloud & AI Models**: Completely unrestricted (Next.js, React, Vue, Swift, Kotlin, Flutter, FastAPI, Node.js, Go, OpenAI/Anthropic/Gemini/open-weight LLMs, AWS, Alibaba Cloud, Vercel, Supabase, etc.).

## 9. IP Ownership, Code License & Disqualification Clauses

Verified from `Gx` and `Zx` in `https://reskilll.com/hack/nexconn/assets/Rules-DQNF0983.js`:

1. **IP Ownership (`Gx`)**: Participants retain **100% ownership** of all intellectual property and source code developed for the hackathon.
2. **Showcase License (`Gx`)**: Participants grant **Nexconn (`RCLOUD GLOBAL PTE. LTD.`)** and **Reskilll** a non-exclusive, worldwide, royalty-free license to showcase and promote submitted projects (title, summary, video, screenshots, public repo link).
3. **Disqualification Triggers (`Zx` & `Submit-R3OJNUmD.js`)**:
   - Submitting an app that uses **only Call SDK** without **Chat SDK** or **Chat UI**, or faking/mocking chat via Firebase/Socket.io/Supabase Realtime while submitting a dormant Nexconn `appKey` with zero real SDK traffic on `console.nexconn.ai`.
   - Submitting a private, deleted, or inaccessible GitHub repository (`repoUrl`).
   - Submitting pre-existing work (`builtBefore: "no"`) without disclosing commits/code created prior to October 23, 2026.
   - Residency in Mainland China (`tS = ["CN"]`) or violating team size limits (>4 members).
   - Plagiarism, malicious code, or fraudulent active-user inflation.
