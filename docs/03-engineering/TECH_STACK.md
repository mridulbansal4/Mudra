## 1. Complete Polyglot Tech Stack Matrix

Per engineering mandate, we reject slow, generic Python web backends (`Flask`/`Django`/`FastAPI`) in the transaction path and pair **Go 1.24**, **Rust 1.85 + WebAssembly**, and **Node.js 22 (`@nexconn/server-sdk`)** with a **React 19 + HeroUI v3 + Tailwind CSS v4 + Lit 3.3.2** web frontend and **Expo + `heroui-native` v2.0.1 + Uniwind** mobile companion app.

| Layer | Choice | Verified Version | Why Chosen (Karpathy / Systems Rationale) | Alternatives Rejected | License |
|---|---|---|---|---|---|
